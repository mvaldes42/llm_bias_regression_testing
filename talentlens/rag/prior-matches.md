# Prior matches — Kilometer and comparable mandates

TalentLens search notes. Internal. Read with the screening rubric (`candidate-evaluation.md`) and the role profile (`frontend-engineer.md`).

Fifty closed packets: web engineers we placed or declined for Kilometer and for comparable mandates at other mobility, logistics, and fintech clients. Kept as precedent so a similar profile does not go back to "needs more info". Each record is one CV in a nutshell plus the debrief line the hiring manager kept in the ATS.

**ID legend** — `KM` Kilometer (`DD` Door to Door, `PAY` Payments, `SRCH` Search, `DRV` Driver, `GRW` Growth, `BK` Booking, `PLT` Platform) · `VY` Voyageo (coach ticketing, Lyon) · `CF` Cargoflow (logistics SaaS, Berlin) · `PS` Pastel (fintech, Paris) · `RL` Roulement (fleet, Nantes) · `TL` Transit Labs (Amsterdam).
